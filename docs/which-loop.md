# Which loop after which change

One table (2026-11-26). It adds no rule: every tool, time and trigger below is copied from the line cited
beside it (`CLAUDE.md:N`, a tool's header `tools/x.mjs:N`, or a workflow `.github/workflows/x.yml:N`). When a
cited line changes, change this table with it. "Not stated" means no header or rule gives a time.

Every row also gets the baseline (first row). "GitHub" is what runs after the push; it never blocks the push or
the Pages deploy, and a red run means "look at the last push" (`checks.yml:9-10`, `browser.yml:17-18`,
`rules.yml:31-32`). "checks.mjs 1xx" means `node tools/checks.mjs` runs that tool itself, so it runs while you
work (the Stop hook), before every commit and push, and on GitHub (`checks.yml:98`).
