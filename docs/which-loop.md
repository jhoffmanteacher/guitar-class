# Which loop after which change

One table (2026-11-26). It adds no rule: every tool, time and trigger below is copied from the source named
beside it: a section of `CLAUDE.md`, a tool's header, a check in `tools/checks.mjs` (by its number), or a job of a
workflow in `.github/workflows/`. When that source changes, change this table with it. "Not stated" means no
header or rule gives a time.

Every row also gets the baseline (first row). "GitHub" is what runs after the push; it never blocks the push or
the Pages deploy, and a red run means "look at the last push" (the headers of `checks.yml`, `browser.yml` and
`rules.yml`). "checks.mjs 1xx" means `node tools/checks.mjs` runs that tool itself, so it runs while you work
(the Stop hook), before every commit and push, and on GitHub (`checks.yml` job `checks`).
